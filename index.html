    ROBOYUDH 2026

    Roboyudh is a premier intercollegiate national-level robotics tournament that brings together top talent from institutions across the country to compete, innovate, and redefine excellence in engineering. This mega event features five high-intensity challenges - Robo Soccer, Robo Sumo, Line Follower, Robo Run, and RC Racing, designed to test participants’ expertise in robotics design, automation, strategy, and real-world problem-solving. Roboyudh aims to create a highly competitive and collaborative arena that inspires technological advancement, encourages interdisciplinary learning, and showcases the nation’s brightest young innovators.


    List Of Events

    Robo Soccer

    The Ultimate Robotic Showdown on the Field! RoboSoccer is a competitive robotics event where teams build robots to play soccer inside an arena.

    Robo Sumo

    Outlast. Outpush. Outplay. RoboSumo is a power driven robotics competition where robots battle inside a circular ring.

    RC Racing

    Fast cars, faster fun! RC Racing is a high speed robotic race where participants control robots through a challenging track.

    Line Follower

    Gear up, it’s time to break through! Line Follower is a robotics challenge where robots autonomously follow a predefined path accurately.

    Robo Run

    Control. Conquer. Clock the fastest run. Robo Run is an obstacle based robotics race.

    GameVerse

    Where fun is the real competition. GameVerse is a non technical entertainment event.
